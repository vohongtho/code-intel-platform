# Code Intel v1.0.10

## Generation V2

Version 1.0.10 preserves atomic index publication while reducing unnecessary disk work. Healthy zero-change analyses keep the current generation unchanged. Known source changes rebuild graph and BM25 for correctness while cloning only `vector.db` when incremental vector mutation is safe. Repository analysis is serialized with `.code-intel/analyze.lock`, and readers can pin graph, BM25, vector, and metadata to one immutable `IndexSnapshot`.

## Agent-aware setup

`code-intel setup [path]` reads the repository selection saved in `.code-intel/agent-targets.json`. It configures MCP and installs only supported global integrations for selected agents. Project-scoped instruction files remain exclusively managed by `code-intel analyze`.

## Compatibility

Generation V1 manifests and legacy flat indexes remain readable. Existing project instruction files and global hooks are not deleted automatically.
